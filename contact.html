확인해 주세요

더 빠르고 정확한 안내를 위해 자주 받는 질문을 정리했습니다.

Java 플랫폼 견적 문의 시 어떤 정보를 준비하면 좋을까요?

아래 정보를 함께 알려주시면 환경에 맞는 구성과 견적을 더 정확하게 안내해 드릴 수 있습니다. 확인이 어려운 항목은 비워두셔도 괜찮습니다.

  • 사용 중인 Java 버전과 배포판 (예: Oracle JDK 8, OpenJDK 17 등)
  • 서버·코어 수 또는 데스크톱 등 사용 환경
  • 클라우드 / 온프레미스 여부
  • 희망 도입 또는 전환 일정
EOL 오픈소스 지원 견적 시 어떤 정보를 준비하면 좋을까요?

HeroDevs Never-Ending Support(NES)는 지원이 종료된 프레임워크·라이브러리별로 제공됩니다. 아래 정보를 알려주시면 지원 범위와 견적을 더 정확하게 안내해 드릴 수 있습니다. 문의 유형은 ‘HeroDevs NES (EOL 오픈소스 지원)’을 선택해 주세요.

  • 사용 중인 프레임워크·라이브러리와 버전 (예: Spring Boot 2.x, AngularJS 1.x, Vue 2 등)
  • 사용 중인 패키지 매니저 (npm, Maven 등)
  • 해당 코드에 커밋하는 개발자 수 (HeroDevs 라이선스는 코드를 커밋하는 사용자 수 기준입니다)
  • 배포 · 운영 환경
  • 희망 도입 일정과 업그레이드 · 마이그레이션 계획
