FAQ

Before you
reach out

To help us answer faster and more accurately, we've gathered the questions we hear most often.

What should I prepare when requesting a Java platform quote?

Sharing the details below helps us recommend the right configuration and give you a more accurate quote. Feel free to leave out anything you're not sure about.

  • Current Java version and distribution (e.g., Oracle JDK 8, OpenJDK 17)
  • Your environment, such as number of servers / cores, or desktops
  • Cloud or on-premises
  • Preferred timeline for adoption or migration
What should I prepare when requesting a quote for EOL open-source support?

HeroDevs Never-Ending Support (NES) is offered per end-of-life framework or library. Sharing the details below helps us give you a more accurate scope and quote. Please select ‘HeroDevs NES (EOL open-source support)’ as the inquiry type.

  • Frameworks / libraries in use and their versions (e.g., Spring Boot 2.x, AngularJS 1.x, Vue 2)
  • Package manager in use (npm, Maven, etc.)
  • Number of developers committing to that code (HeroDevs licenses are based on the number of users who commit code)
  • Deployment and operating environment
  • Preferred adoption timeline and any upgrade or migration plans
