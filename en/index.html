Open Source EOL · Never-Ending Support

Support has ended.
Security doesn't have to.

HeroDevs Never-Ending Support (NES) provides security-patched, drop-in replacements for open-source frameworks and libraries that have reached end of life (EOL). Stay secure and compliant on the versions you already run.

Explore HeroDevs NES
Azul + HeroDevs = EOL coverage from runtime to framework

  • Drop-in replacement, no code changes

    Point your package manager at the NES registry and rebuild — that's it. The same version line and APIs mean no changes to your code or CI pipeline.

  • Ongoing CVE patches

    A new NES release ships whenever a CVE is fixed in a supported version, and critical vulnerabilities are covered by an SLA to remediate within 14 days of discovery.*

  • Help with regulations and audits

    Every fix comes with VEX documentation and a signed legal attestation, helping you with security audits and requirements such as SOC 2, PCI-DSS, and the CRA.
