Why Azul, why now

Java 라이선스 비용,
이제 다시 계산할 때입니다

2023년 1월부터 Oracle Java SE Universal Subscription은 실제 Java 사용량이 아닌 전체 직원 수를 기준으로 가격이 책정됩니다. Azul은 코드 수정 없이 그대로 교체할 수 있는 TCK 인증 OpenJDK로 비용은 낮추고, 보안과 지원 수준은 그대로 지킵니다.

직원 수 기준 과금 구조

Java를 사용하지 않는 직원까지 모두 과금 대상에 포함되어, 조직 규모가 클수록 비용 부담이 커집니다.

코드 수정 없는 Drop-in 대체

Java SE TCK 검증을 통과한 100% 오픈소스 빌드. 대부분의 서버 애플리케이션은 설치, JAVA_HOME 변경, 재시작만으로 전환됩니다.

Oracle과 같은 보안 업데이트 주기

분기별 CPU·PSU 업데이트와 수시 긴급 패치를 제공합니다. Azul은 Oracle을 제외하고 CPU와 월간 CSPU를 모두 제공하는 유일한 Java 벤더입니다(Azul 발표).

Oracle Java → Azul

Oracle Java에서 Azul로,
안전하게 전환하세요

앨리웍스는 Azul Authorized Migration Advisory & Services Partner입니다. 현황 진단부터 전환, 이후 기술지원과 유지보수까지 한 팀이 책임집니다.

  • Migration Advisory Partner
  • Migration Services Partner
  1. STEP 01

    진단 · 인벤토리

    운영 중인 JVM과 Oracle Java 사용 현황을 목록화하고 전환 대상과 범위를 파악합니다.

  2. STEP 02

    전환 계획 · PoC

    마이그레이션 플레이북을 수립하고, 핵심 애플리케이션으로 사전 검증(PoC)을 진행합니다.

  3. STEP 03

    전환

    새 OpenJDK 배포판 설치, JAVA_HOME 변경, 재시작. Applet 등 레거시 기술은 대체 방안을 적용합니다.

  4. STEP 04

    검증 · 기술지원/유지보수

    분기별 보안 업데이트(CPU) 주기에 맞춰 컴플라이언스를 유지하고, 앨리웍스가 지속 지원합니다.

문의하기
Azul Zulu와 Azul Platform Core는 어떻게 다른가요?

Azul Zulu는 Azul이 만드는 OpenJDK 빌드입니다. Azul Platform Core(구 Zulu Enterprise / Embedded)는 이 Azul Zulu 빌드를 기반으로 분기별 CPU · PSU 보안 업데이트, Java 6 · 7 레거시 지원, IP 보호 및 면책, Standard · Premium 기술지원을 더한 엔터프라이즈 제품입니다.

전환할 때 애플리케이션 코드를 수정해야 하나요?

Azul Platform Core는 Java SE TCK 검증을 통과한 Oracle Java SE의 일대일 drop-in 대체 제품입니다. Azul에 따르면 대부분의 서버 애플리케이션은 새 OpenJDK 배포판 설치, JAVA_HOME 변경, 재시작만으로 전환됩니다. Azul Platform Prime 역시 코드 수정이나 재컴파일이 필요하지 않습니다.

앨리웍스는 사전 진단과 PoC로 고객 환경에서의 전환 가능성을 먼저 확인합니다.

어떤 Java 버전과 플랫폼을 지원하나요?

LTS 버전인 Java 8, 11, 17, 21, 25와 STS 릴리스를 지원하며, Java 6 · 7은 레거시 프로덕션 지원을 제공합니다. LTS 버전은 최소 8년의 프로덕션 지원(+2년 연장 지원)을 받습니다.

운영체제는 Linux, macOS, Windows, 아키텍처는 x64, ARM, Alpine 등을 지원하며 패키지 매니저, 컨테이너 이미지, 직접 다운로드로 설치할 수 있습니다.

기술지원은 어떻게 받나요?

Azul 한국 공식 총판인 앨리웍스가 도입 상담, 전환, 기술지원과 유지보수를 국내에서 직접 제공합니다. 여기에 Azul의 지원 등급이 더해집니다.

Standard는 업무 시간 지원과 익영업일 응답, Premium은 24x7x365 지원과 1시간 이내 최초 응답을 제공합니다.

Spring 등 프레임워크의 지원 종료(EOL)는 어떻게 대응하나요?

Azul은 JDK(Java 런타임)를 지원합니다. 그 위에서 동작하는 Spring Boot · Spring Framework, Tomcat, Struts, Log4j 1 등 지원이 끝난 프레임워크·라이브러리는 HeroDevs Never-Ending Support(NES)로 보안 패치를 이어받을 수 있습니다. 같은 버전 라인과 API를 유지하므로 패키지 매니저(Maven 등)의 저장소 설정만 바꿔 다시 빌드하는 방식입니다.
